# Adidas Sales Analysis Dashboard

## Project Overview
An interactive Power BI dashboard designed to analyse Adidas sales performance and identify trends across products, regions, retailers, and time periods.

## Dashboard Preview
![Adidas Sales Dashboard](dashboard.png)

## Key Features
- **Sales Performance:** Total sales, operating profit, units sold, and operating margin.
- **Monthly Trends:** Track changes in sales over time.
- **Regional Analysis:** Compare sales across US regions and states.
- **Product Analysis:** Identify top-performing product categories.
- **Retailer Analysis:** Compare sales across retail partners.
- **Interactive Filtering:** Explore results using region and date filters.

## Key Insights
- Total sales reached **$859M**, with **$317M** in operating profit.
- The **West** was the highest-performing region.
- **Men's Street Footwear** generated the highest sales among product categories.
- **West Gear** was the leading retailer.
- **July** recorded the highest monthly sales in the dashboard.
